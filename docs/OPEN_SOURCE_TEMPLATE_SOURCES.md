# Open-source template source registry

Resume Studio uses native HTML/CSS implementations. The repository does **not** redistribute third-party PSD/FIG binaries, screenshots, or proprietary marketplace files.

## Magnific policy

Magnific's current documentation says Free-license resources can be used commercially with attribution, but the license also prohibits sublicensing or redistributing the original file and requires visible attribution. It also states that resources used in products sold to multiple clients must be secondary elements unless the applicable merchandise license applies.

Therefore Resume Studio does **not** bulk-import Magnific stock/template files into its template library. If a specific Magnific asset is later approved for use, keep its downloaded license document and attribution record with the project and do not redistribute the original file.

## Template policy

- Every template in `www/js/templates.js` is rendered as editable HTML/CSS.
- Content editing changes text/data only; the template's typography/layout rules remain fixed.
- Preview thumbnails use the same A4 rendering primitives as the live canvas rather than external screenshot images.
- Open-source code may only be copied when its license permits it; otherwise the implementation is recreated independently.
- Third-party licenses and notices must be preserved when third-party code/assets are actually redistributed.
